# OhMyPassword

本地密码管理器，包含浏览器插件、桌面客户端和 Android / iOS 客户端。密码在设备上加密保存，通过局域网检测设备并手动合并密码本，不依赖云端密码服务器。

当前主干为 **0.2.5**：锁定客户端界面后，浏览器插件仍可查询、填充和保存密码；需要停止插件时选择「完全锁定并停止插件」。首次启动或重启仍需输入主密码，不保存主密码用于自动解锁。

合并采用单向接收。需要密码的设备发起请求、两端确认后，只有发起方导入对方当前有效的密码；提供方密码库不会被修改，删除记录不会传给其他设备。插件免连接令牌、设备免邀请码；每 **5 分钟**自动检测，也可手动检测。

设备同步页显示本机版本、局域网 IPv4 地址，以及主动扫描的「已检测地址 / 总数」、百分比和实际扫描范围；局域网广播的自动发现另有约 20 秒倒计时。客户端明确标注已验证兼容 0.2.3、0.2.4、0.2.5，0.2.2 及更早版本不兼容。发现协议 2 的旧版设备时仅提示更新，不允许合并；未提供具体版本的设备不会被猜测版本号。

如果旧版合并后密码列表变空，请先停止合并并保留两台设备的数据，按 [历史恢复说明](RECOVERY.md) 备份原库，再检查本机历史。旧版会双向传播删除；是否能恢复取决于原历史或备份是否仍在，不能保证所有情况都可找回。

## 三个软件目录

| 目录 | 软件与平台 | 负责什么 |
| --- | --- | --- |
| [`extension/`](extension/) | Chrome / Edge 浏览器插件 | 连接本机客户端；按当前网站主域名查找账号；用户选择后填充；确认保存新增或修改的账号密码 |
| [`desktop/`](desktop/) | Windows / macOS / Linux 客户端 | 加密密码库、账号管理、免令牌的本机插件接口、自动/手动检测设备、手动合并密码本 |
| [`mobile/`](mobile/) | Android / iOS 客户端 | 共用密码库和管理界面；前台解锁时检测设备与手动合并，后台完全锁定，返回前台并解锁后恢复检测 |

桌面与移动端共用 `desktop/core/` 的加密与版本合并、`desktop/service/` 的接口与同步协议，以及 `desktop/src/` 的界面。`mobile/` 提供独立手机构建入口和 Android NSD / iOS Bonjour 适配；三个目录属于同一工作区，请克隆完整仓库。

## 使用流程

1. 在客户端创建密码库，设置主密码和设备名称。主密码只用于本机解锁；另一设备可以使用不同主密码。
2. 添加网站 hostname、账号与密码。列表默认隐藏账号，在顶部开启「账号明文显示」后可查看用户名，关闭或锁定后恢复隐藏；密码仍需打开记录后显示或复制。
3. 在另一台设备安装并创建自己的密码库。两台设备连接到可互通的局域网，打开并解锁客户端。
4. 在**需要取得密码的设备**打开「设备同步」，等待自动检测或点击「手动检测设备」。选择保存着密码的设备，点击「接收对方密码」。核对两端会话编号一致，发起方选择「编号一致，接收到本机」，提供方选择「编号一致，允许提供」。无需邀请码。
5. 只有发起方合并并保存。成功后，发起方显示「已合并密码本」，提供方显示「已向对方提供密码，本机密码未修改」。空来源会明确提示没有可接收的密码，不会清空本机已有记录；拒绝、超时、锁定或写入失败会显示对应状态。
6. 安装浏览器插件，打开并首次解锁本机客户端即可使用；之后手动锁定界面或闲置 15 分钟自动锁界面，不影响插件。需要停止插件时，选择「完全锁定并停止插件」或退出客户端。默认直接访问 `127.0.0.1:17841`，无需连接令牌或额外授权步骤。
7. 新增、修改和删除只保存在本机。需要另一台设备取得新增或修改时，在那台设备上发起「接收对方密码」。删除始终只影响本机，不传播到其他设备。
8. 需要找回本机旧版本或已删除记录时，点击密码库列表上方的「历史恢复」，选择条目及版本，再确认恢复到本机；即使当前列表为空也可访问。恢复前会创建加密备份，旧历史仍保留。

从 0.1.0 升级时请同时更新客户端和插件。原有加密密码库继续使用；插件会清理旧连接令牌，新流程不使用旧邀请码或长期自动同步权限。0.2.3、0.2.4、0.2.5 的局域网发现与接收使用协议 3，已验证可互相接收；0.2.2 及更早版本使用的旧版双向协议不兼容。0.2.4 起可将探测到的协议 2 设备列为需更新设备，但不能与其合并。本机浏览器接口仍使用协议 2，不受这次局域网协议变更影响。

**Android 升级限制：** 0.2.5 的开发 APK 与 0.2.4、0.2.3、0.2.2、0.2.1、0.2.0、0.1.0 的签名证书不同，不能直接覆盖安装。不要通过卸载旧应用来升级尚未迁出的唯一密码库：卸载会删除应用数据，且 Android 系统备份已禁用。请保留旧应用和数据，先确认密码已完整保存到其他可访问设备或完成可恢复的备份。桌面端的旧密码库读取已通过实际升级验证。

浏览器插件不自动提交登录表单，不静默收集所有网站的密码，也不把密码库保存在浏览器存储中。首版没有移动系统自动填充扩展；手机其他 App 的自动填充需后续接入 Android Autofill / iOS Credential Provider。

## 网站账号匹配

客户端查询和浏览器插件按可注册主域名匹配：例如 `login.example.com`、`www.example.com`、`example.com` 可以找到同一组账号，`a.example.co.uk` 与 `b.example.co.uk` 也相同。使用内置的 Public Suffix List（包含 PRIVATE 规则），`alice.github.io` 与 `bob.github.io` 这类独立站点分开匹配。IP、本地地址及未知后缀仍要求完整 hostname 一致。

原有密码记录继续保存完整 hostname；查找不会合并或改写记录，插件显示每个账号原来保存的网站。修改匹配到的账号保留其原网站和 ID。使用本版功能请同时更新客户端和插件；当前页面发生跳转时仍需重新打开插件后选择账号。

## 常用登录页

插件已加入 Apple / iCloud、ChatGPT / OpenAI、Gmail / Google、Gitee、163 / 126 邮箱，以及 GitHub、微软个人账号、百度和哔哩哔哩的登录页规则。分步登录时先填写账号，由用户点击网站的下一步；如进入密码步骤，再次选择账号填充。验证码、通行密钥和第三方登录由网站正常处理，插件不自动点击登录或提交表单。

Apple 与网易邮箱的嵌入式登录框首次需要点击插件中的授权按钮。权限仅限明确列出的登录框地址；拒绝授权时仍可从客户端复制账号密码。登录页可能随网站更新而变化，已验证范围与使用说明见 [插件文档](extension/README.md)。

## 合并规则

- **只有请求方接收**：提供方只发送当前有效记录，不接收请求方的密码，也不因这次操作修改自己的密码库。
- **保留本机数据**：来源缺少某条密码或完全为空，都不会删除请求方已有记录。导入沿用记录 ID，不用远端快照覆盖整库。
- **最新修改为准**：同一条记录按修改时间、计数和设备 ID 比较，较新的版本生效；收到数据保留原修改时间，重复拉取不会创建重复记录。
- **不传播删除**：只传当前有效版本，不传删除标记或全部历史。本机较新的删除标记仍保留；若要重新启用这条记录，请从「历史恢复」明确恢复。
- **先备份再写入**：有变更的接收和历史恢复，会先保存当前加密库与设备标识的独立备份；备份失败时不修改密码库。详见 [恢复说明](RECOVERY.md)。
- **每次手动确认**：设备检测只更新列表；每次接收都需两端核对并确认，完成一次不会开启之后的自动同步。接收方已经取得的数据副本无法远程收回。
- **注意设备时钟**：离线场景没有统一服务器时间，请开启系统自动校时。已收到的版本会参与本地版本时钟，严重错误的设备时钟仍不能代表真实操作顺序。

首版的全部记录、历史及删除标记合计最多 **1 MiB 序列化数据**，超限会明确拒绝保存或合并，不会先报告成功再丢弃数据。当前没有历史清理或附件功能。

## 服务与手机后台限制

| 通道 | 默认端口 | 用途 |
| --- | --- | --- |
| `127.0.0.1` HTTP | `17841` | 插件免令牌直连，校验准确扩展来源、Host 和解锁状态 |
| 局域网 HTTP | `17842` | 协议 3 的单次加密接收，只更新发起方 |
| mDNS / Bonjour | 系统服务发现 | 寻找 `_ohmypassword._tcp.`，不广播凭据或密钥 |

电脑客户端首次解锁后，在同一次运行期间保留插件访问；界面锁定会隐藏本机列表并停止局域网检测和合并，插件仍可查询和保存。完全锁定或退出会停止插件访问并清除内存中的解密状态；重启需要再次解锁。手机在前台解锁时运行，进入后台会完全锁定、停止插件与局域网服务，结束尚未完成的合并会话；返回前台解锁后恢复检测。普通 iOS 密码管理器无法常驻 HTTP 服务；换成 WebSocket 或 TCP 同样受系统限制。

界面锁定期间，解密密钥与密码库仍保留在客户端进程内，供本机插件访问；完全锁定才停止插件读取与保存。Wi-Fi 客户端隔离、防火墙、局域网权限拒绝或跨子网可能影响发现与连接。默认只允许 OhMyPassword 插件的浏览器来源，普通网页不能任意获取密码；免令牌模式无法认证自行构造 HTTP 请求的本机原生程序，解锁期间需要信任本机程序。

首版局域网传输使用 IPv4；自动发现与手机原生适配也选择 IPv4 地址。

## 构建

需要 Node.js 22+、Rust stable，以及 [Tauri 平台开发依赖](https://v2.tauri.app/start/prerequisites/)。Android 另需 JDK / Android SDK / NDK；iOS 构建需 macOS 与 Xcode。

```sh
git clone https://github.com/ecojust/OhMyPassword.git
cd OhMyPassword
npm ci
npm run build
```

桌面开发与打包：

```sh
npm run tauri --workspace @ohmypassword/desktop -- dev
npm run tauri --workspace @ohmypassword/desktop -- build
```

浏览器插件：

```sh
npm run build --workspace @ohmypassword/extension
npm run test:extension
```

手机构建步骤与必要配置见 [`mobile/`](mobile/)。Android 开发签名包可以安装测试；iOS 模拟器构建无需分发证书，真机安装与分发需自己的 Apple 签名。最新构建结果见 [GitHub Actions](https://github.com/ecojust/OhMyPassword/actions)。

核心与服务测试：

```sh
npm run test:core
npm run test:service
```

加密、授权、同步与平台边界详见 [架构说明](ARCHITECTURE.md)、[安全说明](SECURITY.md) 和 [验证记录](VALIDATION.md)。
