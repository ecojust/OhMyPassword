# OhMyPassword 本地服务与手动合并

桌面端与 Android / iOS 共用的 Rust 服务，当前网络协议为 **2**。密码库格式仍由 `ohmypassword-core` 管理。服务不提供网络解锁接口；锁定或暂停时不能读取密码、批准请求或继续合并。

## 浏览器接口

仅监听 `127.0.0.1:17841`，官方 Chrome / Edge 插件无需填写 token。服务通过 `browser-origin.txt` 固定插件 Origin，校验准确的 Host、Origin、JSON 类型与解锁状态；普通网页、其他扩展、缺少 Origin 的密码请求均被拒绝。旧 token 和客户端授权表不参与判断。

| 接口 | 请求 | 响应 |
| --- | --- | --- |
| `GET /v1/status` | 无凭据 | `{protocol:2, initialized, locked}`，不含库内容 |
| `POST /v1/browser/connect` | 官方插件 Origin | `{connected:true, protocol:2}` |
| `POST /v1/credentials/search` | JSON `{hostname}` | `{entries:[…]}`，精确 hostname 匹配 |
| `POST /v1/credentials` | JSON `EntryInput` | `{entry:…}`，只保存本机 |

路径保留 `/v1` 供插件调用，但响应明确标识协议 2。Chromium 扩展的跨域 GET 可能省略 Origin，因此插件使用 POST 搜索；兼容 GET 搜索仍严格要求 Origin。接口不需要 `Authorization`，预检只允许 `Content-Type`；所有响应禁止缓存。公开状态接口可供插件区分“服务未运行”和“密码库已锁定”。

固定 Origin 用于隔离网页和非官方扩展；它不是对拥有本机进程权限的恶意软件进行认证的机制。

## 设备发现

- 默认每 **300 秒**检测一次，用户也可调用 `detect_devices()`；手动检测或恢复应用后重新安排下一轮检测。每轮浏览 20 秒，设备列表保留最近 660 秒内实际发现的结果。
- 桌面使用 `_ohmypassword._tcp.local.` mDNS-SD，TXT 为 `protocol=2` 和 `device_id`；手机通过原生 NSD / Bonjour 将新结果交给服务。广播不包含密码或密钥。
- 检测只更新设备列表。新增、修改、删除密码、浏览器保存、解锁和恢复应用，都不会触发密码交换。
- 首版支持 IPv4 私网、回环和链路本地地址。LAN 服务默认端口 `17842`；只使用数字 IP，不解析远端 URL 主机名、不跟随重定向、不使用系统代理。

## 一次性手动合并

1. 发起端从已发现的设备中选择“合并密码本”，`request_merge(device_id)` 立即返回单次会话。后台只进行握手，不读取或发送密码。
2. 双方先交换对临时 X25519 公钥与随机 nonce 的承诺，再揭示并验证。会话密钥与六位核对编号由 HKDF 派生，绑定双方设备 ID、公钥、nonce、服务 epoch 和合并会话 ID；拒绝无效或全零共享密钥。
3. 双方屏幕显示相同编号。两端都核对后点击确认；编号无需输入或复制，不使用邀请码，也不建立长期配对授权。握手尚未完成、只有一端确认、拒绝或过期时不能开始密码交换。
4. 密码快照经 AES-256-GCM 加密传输，AAD 绑定方向、路由、设备 ID、会话 ID、请求 ID 与 epoch。密码及删除标记仍按核心库最新修改规则合并；收到数据不刷新修改时间，旧快照不会替换并发产生的新记录。
5. 接收方先持久化合并结果并返回快照摘要；发起方合并落盘后核对同一摘要。发生并发修改时最多重算三轮。最终 ACK 的短暂网络窗口由核心写保护阻止本机其他写入，确认双方同一已落盘快照后，状态才变为 `completed`，界面显示“已合并密码本”。丢失 ACK 可通过同一请求的缓存回复或加密状态回执确认。

本次合并完成后的新编辑仍只在本机，需要再次手动合并。拒绝、取消、超时、锁定或退出会停止本轮；已成功落盘的记录不会伪装成已回滚。若只完成一端写入而无法取得双方确认，返回未完成状态，不显示双端成功。

会话最长五分钟。锁定/暂停时清除会话密钥、请求记录和发现列表，并轮换服务 epoch，旧编号与迟到请求不能恢复授权。完成后的短期会话仅允许回执查询和原 ACK 幂等重试，不能再次读取新密码。旧 `/v1/pair`、`/v1/sync` 路由及自动同步 worker 已移除，旧磁盘配对信息不会重新启用它们。

## 资源与边界

核心密码记录及历史合计上限 1 MiB，HTTP 消息上限 2 MiB（包含加密/Base64 开销）。容量或落盘失败不会部分覆盖本机密码库。处理中的 HTTP 请求上限为 8，LAN 每个源地址每分钟最多 64 个请求；网络请求设有超时，服务停止具有有限等待。这不是 TCP 层抗拒绝服务保证。

手机仅在系统允许运行且密码库解锁时检测/合并，不承诺后台常驻。不同网段、Wi-Fi 客户端隔离和防火墙可能阻止设备直连。

## 验证

```sh
cargo test --locked --manifest-path desktop/service/Cargo.toml
```

测试使用真实本机 HTTP 套接字和独立加密密码库，覆盖免 token 官方插件接口、非法 Origin/Host、发现不交换数据、双端手动确认、拒绝/锁定/到期、最新修改与删除、旧路由失效、容量失败、commit-reveal/全零密钥、单次授权、防重放、ACK 幂等、最终写保护、丢失 ACK 恢复及有限时间退出。真实手机、跨设备 mDNS 和各类局域网仍需实测。
